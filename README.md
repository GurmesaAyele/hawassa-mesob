# Hawassa MESOB - Government Service Portal

Complete digital platform for Hawassa MESOB (Multi-Service One-Stop Center).

## 📁 Project Structure

```
hawassa-mesob/
├── frontend/          # React + Vite frontend application
│   ├── src/          # Source code
│   ├── public/       # Static assets
│   └── ...          # Config files
└── README.md         # This file
```

## 🚀 Getting Started

### Frontend Development

```bash
cd frontend
npm install
npm run dev
```

Visit `http://localhost:5173`

### Build for Production

```bash
cd frontend
npm run build
```

## 📦 What's Inside Frontend

- **React 18.3.1** - Modern UI library
- **Vite 8.3.3** - Fast build tool
- **Tailwind CSS 4.3.3** - Utility-first CSS
- **React Router DOM** - Client-side routing

### Key Features Implemented

✅ Modern Header (matching Addis MESOB design)
✅ Hero Section with search
✅ AI Chatbot Assistant (MESOB AI)
✅ Service Categories & Directory
✅ Comprehensive Mock Data (25+ services, 12 organizations)
✅ Reusable Component Library
✅ Responsive Design
✅ Multi-language Support (EN/AM/Sidama)
